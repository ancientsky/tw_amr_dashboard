## Ground rules (parallel agents share one working tree)
- Only create/edit files inside YOUR feature directories. Exceptions, append-only and with the Edit tool (never Write/overwrite):
  `src/i18n/{zh-TW,en,ja}.json` (add your keys under your own top-level namespace, e.g. `"resistance": {...}`, identical key sets in all 3 files — `npm test` checks this),
  `src/embed/registry.ts` (register your embeddable charts via `registerEmbedChart`, keeping your chart components in your own dir).
  Re-read a shared file immediately before each Edit; other agents are editing it too.
- Never run `git commit`/`git push`; the supervisor does. Never run `npm install` of new packages without need — the stack is fixed (echarts, framer-motion, html-to-image, world-atlas, topojson-client).
- Done = `npm run build && npm run lint && npm test` pass, and `node scripts/screenshot.mjs --routes=<your routes>` shows your pages in light/dark × zh-TW/en/ja without console errors (screenshots land in `screenshots/`, gitignored; look at a few PNGs with the Read tool).
- All visible strings via `t()`; zh-TW primary, en and ja real translations. Numbers via `fmtPct`/`fmtNumber`. Respect reduced motion.
- Every chart in a `ChartCard` with `title`, `subtitle`, `source`, `chartRef`, `tableRows`/`csvRows`, `fileName`, `link` (deep link via `useHashQuery().link`), `embed` where an embed chart exists, `keyNumber` where a headline figure exists, and `dataset="…"` so provisional chips/precision badges appear automatically.

## Real data facts (public/data/*.json; loaders: `useDataset('resistance')` etc.)
- **resistance** (6,463 rows, `provisional:false`, years 2017–2024): dims pathogens(30), antibiotics(46), antibioticClasses(24), phenotypes(9: CRAB, CRE, CR-ECO, CRKP, CRPA, MRSA, VRE, VR-EFA, VR-EFM), levels(all, medical_center, regional, district), wards(all only), settings(all, co, ho), specimens(all, blood, urine, sputum, pus, stool), precisions(table, text, chart_estimate).
  - Two row kinds: **antibiogram rows** (`phenotype` undefined; from the printed 敏感性圖譜 tables; `precision:'table'`; `resistant_pct = 100 − %S` i.e. non-susceptible; `isolates` = tested; one per data year 2022/2023/2024 × level × pathogen × antibiotic; specimen 'all', setting 'all') and **pathogen bar-chart rows** (no phenotype, specimen/setting vary, data years 2022–2024, precision text|chart_estimate, optional ci_low/ci_high) and **MDRO trend rows** (`phenotype` set, years 2017–2024, level all/medical_center/regional/district, setting all/co/ho, precision text|chart_estimate). ALWAYS filter on `phenotype` presence to pick the kind you want. Use `dedupeResistance`/selectors which already prefer table > text > chart_estimate then newest reportYear.
  - Pathogen codes: SAU, ENC(Enterococcus spp.), EFM, EFA, SPN, GAS, GBS, CDI, ENB(Enterobacterales), ECO, KPN, ECL, PMI, CIT, SMR, MOR, PRV, SAL, NTS, SHI, PAE, ABA, SMA, BCC, CIN, ELI, HIN, NGO, HPY, BFR. `dims.pathogens[].meta` has gram, whoPriority (critical/high/medium), keyPhenotype, short name.
  - Antibiotic codes: OXA PEN PEV AMP AMX PIP AMC SAM TZP CZO CXM CXA FOX CTX CRO CAZ CFP CFM FEP ATM IPM MEM ETP DOR GEN GEH AMK CIP LVX MFX ERY CLR CLI TCY MNO TGC VAN DAP LNZ QDA COL SXT CHL RIF NIT MTR; `dims.antibiotics[].group` = class code; `dims.antibioticClasses` for ordering.
  - National (level all, setting all) 2024: CRAB 58.4, CRE 6.1, CR-ECO 3.0, CRKP 15.6, CRPA 13.4, MRSA 48.0, VRE 18.0, VR-EFA 0.4, VR-EFM 48.0. 2017→2024 story: CRAB 53→65 (2022 peak)→58; CRKP 10→16; VR-EFM ~50→57 (2021)→48; MRSA ~48 flat; HO (hospital-onset) far higher than CO for every MDRO (e.g. CRKP HO 29.5 vs CO 11.5). District hospitals highest for CRAB/MRSA; medical centres highest for CRE/CRKP in some years.
- **isolates** (2,114 rows): organism counts by year × scope (all, blood, urine, sputum, pus, stool, co, ho) × level, with rank (top-10 tables), plus MDRO chart counts with `subset` ('I+R' resistant / 'S') — never sum subsets with totals. Total isolates rose from ~603k (2019) to ~756k (2024); hospitals reporting 134 (2017) → 329 (2024).
- **antibiotic_use** (736 rows, **provisional model**): metrics DID (inpatient DDD/1000 patient-days), by level, class codes with `dims.classes[].meta.aware`; `TOTAL` = J01 total (exclude when summing). **hai** (2,080 rows, provisional) metrics hai_density, clabsi, cauti, vap, utilization ratios by icu_type/level; **hai_pathogens** (960, provisional) rank lists. **glass** (402 rows, provisional curated approximations of WHO GLASS 2022 + national systems; 41 countries + TWN; indicators MRSA_BLOOD, 3GC_R_ECO_BLOOD, CR_ECO_BLOOD, 3GC_R_KPN_BLOOD, CR_KPN_BLOOD, CR_ABA_BLOOD, CR_PAE_BLOOD, VRE_EFM_BLOOD, FQ_R_ECO_BLOOD, PNSP_BLOOD; TWN rows derived from real data, `meta.comparability.TWN[indicator]` says how; `dims.countries[].meta` has whoRegion/iso3). **links** (60), **glossary** (70), **kb** (138), **meta** (latestYear 2024, yearsAvailable, provisionalDatasets, ingestion.pdfs with sha256, sources).
- Static API: `public/api/v1/index.json`, `openapi.yaml`, `<dataset>.json|.csv`, slices `resistance/pathogen/{CODE}.json`, `resistance/phenotype/{CODE}.json`, `resistance/year/{YYYY}.json`, `antibiotic-use/year/{YYYY}.json`, `hai/year/{YYYY}.json`, `glass/indicator/{CODE}.json`, `glass/country/{ISO3}.json`. Base URL https://ancientsky.github.io/tw_amr_dashboard/api/v1/ . Docs: docs/API.md, docs/DATA.md, docs/EMBED.md.

## Component APIs (from the scaffold)
- `useDataset(name)` → `{status:'loading'|'ready'|'empty'|'error', data, error}`; `useMeta()`, `useDatasetProvisional(name)`, `useToast()`.
- Selectors: `filterResistance`, `sliceResistance` (defaults strata to 'all'), `filterYears`, `parseYearRange`/`formatYearRange`, `latestValue` ({value, prevYear, delta}), `pivotPathogenAntibiotic`, `buildSeries`, `resistanceTrend(records, filter, groupBy)`, `seriesToRows`, `precisionBadge`, `worstPrecision`, `dedupeResistance`, `filterIsolates`, `topIsolates`, `isolateTrend`, `sortByDimOrder`, `antibioticsFor`.
- Format: `fmtPct`, `fmtNumber(n,{compact})`, `fmtDelta`, `dimName(dims, code, locale)`, `dimNamer`, `slugify`, `toCsv`.
- `useT()` → `t(key, vars)`, `t.tl(localizedText)`, `t.locale`. `useHashQuery()` → `{params, get, getAll, set(patch,{replace}), link(extra), path}`; `useQueryParam(key, fallback, allowed?)`.
- `EChart` props: option, ariaLabel (required), height, loading, notMerge, onEvents, onReady; ref `getInstance()`. Maps: `await ensureWorldMap()` from `components/chart/worldMap`.
- `ChartCard` props: id, title, subtitle, source, eyebrow, provisional | dataset, precision, badges, status, onRetry, height, chartRef, tableRows, tableColumns, csvRows, fileName, link, embed {chart, params}, keyNumber {value,label}, compact, toolbar, actions, footer.
- `Kpi` props: label, value, format, unit, delta, deltaUnit, deltaLabel, goodDirection ('down' default), trend|sparkline, badge, caption, accent, onClick. `AnimatedNumber`, `Badge`, `Tabs`, `Select`, `MultiSelect`, `RangeSlider`, `SegmentedControl`, `DataTable`, `EmptyState`, `Skeleton`, `Tooltip`, `Modal`, `Drawer`, `IconButton`, icons, `Field`, `Sparkline`, `Toast`.
- Palette: `CATEGORICAL[theme]`, `seriesColor(i)`, `colorMap(keys)`, `resistanceColor(pct, theme)`, `resistanceRamp`, `LEVEL_ORDER`.
- Layout: `PageHeader`, `Section`, `ProvisionalBanner` (auto), `openChat()` for the chatbot.
- Embed: `registerEmbedChart({ id, route, params, Component })` in `src/embed/registry.ts`; embed pages are rendered by `src/embed/main.tsx` from `embed.html#/?chart=<id>&...`.
