# TW-AMR Watch — static data API (v1)

**Base URL:** `https://ancientsky.github.io/tw_amr_dashboard/api/v1`

The API is a set of static JSON and CSV files generated by `scripts/build_data.py` and served by GitHub Pages:
* read-only `GET`, with no key, no auth and no query parameters (filters are pre-sliced into paths);
* **CORS:** GitHub Pages sends `Access-Control-Allow-Origin: *`, so any web page can `fetch()` the files directly;
* machine-readable description: [`openapi.yaml`](https://ancientsky.github.io/tw_amr_dashboard/api/v1/openapi.yaml)
  (OpenAPI 3.1) and JSON Schemas under `/schema/`;
* catalogue: [`index.json`](https://ancientsky.github.io/tw_amr_dashboard/api/v1/index.json), which lists every dataset with
  record counts, `provisional` flags, JSON/CSV/schema URLs, every slice URL and `generatedAt`.

> **Always check `provisional`.** `resistance` and `isolates` are transcribed from the Taiwan CDC AMR annual reports
> (per-record `precision`: `table` exact, `text` exact, `chart_estimate` ≈ ±1–2 points). `antibiotic-use`, `hai`,
> `hai-pathogens` and `glass` are **provisional estimates** (`provisional: true`), not official statistics. See `docs/DATA.md`.

## Endpoints

| Path | Content |
|---|---|
| `/index.json` | catalogue (datasets, counts, slice URL templates and values, generatedAt) |
| `/meta.json` · `/meta.csv` | site metadata: latestYear, yearsAvailable, provisionalDatasets, ingested PDFs (sha256) |
| `/resistance.json` · `/resistance.csv` | % resistant by year × pathogen × antibiotic (× phenotype) × level × setting × specimen |
| `/resistance/pathogen/{CODE}.json` | one organism, e.g. `/resistance/pathogen/KPN.json` |
| `/resistance/phenotype/{CODE}.json` | one MDRO indicator, e.g. `/resistance/phenotype/CRAB.json` |
| `/resistance/year/{YYYY}.json` | one data year, e.g. `/resistance/year/2024.json` |
| `/isolates.json` · `/isolates.csv` | isolate counts and ranks (表 2-x) and MDRO counts by level × CO/HO (`subset:"I+R"|"S"` = split counts, absent = totals) |
| `/antibiotic-use.json` · `.csv` | *provisional* DDD/1000 patient-days by class × level × year (+ AWaRe) |
| `/antibiotic-use/year/{YYYY}.json` | one year |
| `/hai.json` · `.csv` | *provisional* HAI density, CLABSI/CAUTI/VAP, device utilisation by level × ICU type |
| `/hai/year/{YYYY}.json` | one year |
| `/hai-pathogens.json` · `.csv` | *provisional* top-10 HAI pathogens by site |
| `/glass.json` · `.csv` | international comparison (10 GLASS indicators; TWN rows computed from Taiwan data) |
| `/glass/indicator/{CODE}.json` | e.g. `/glass/indicator/CR_KPN_BLOOD.json` |
| `/glass/country/{ISO3}.json` | e.g. `/glass/country/TWN.json`, `/glass/country/JPN.json` |
| `/links.json` · `/glossary.json` · `/kb.json` (+ `.csv`) | dashboard directory, glossary, chatbot knowledge base |
| `/schema/{name}.schema.json` | JSON Schema (draft 2020-12) for each dataset; `common.schema.json` holds shared `$defs` |
| `/openapi.yaml` | OpenAPI 3.1 description of all of the above |

The valid `{CODE}` / `{YYYY}` / `{ISO3}` values for each slice are listed in `index.json → datasets[].slices[].values`
and as `enum`s in `openapi.yaml`. An unknown value returns 404.

### Response shape
Every JSON file (including slices) is an envelope:
```json
{
  "dataset": "resistance", "version": "1.0.0", "generatedAt": "2026-10-20T06:44:36Z", "provisional": false,
  "sources": [{"id": "tw-cdc-amr-2024", "title": {"zh-TW": "…", "en": "…", "ja": "…"}, "publisher": "衛生福利部疾病管制署 Taiwan CDC", "year": 2024, "url": "…", "kind": "annual-report"}],
  "notes": {"zh-TW": "…", "en": "…", "ja": "…"},
  "slice": {"by": "phenotype", "value": "CRAB", "of": "resistance"},
  "meta": {"coverage": {…}, "precisionSummary": {"table": 4790, "text": 15, "chart_estimate": 898}},
  "dims": {"pathogens": [{"code": "ABA", "name": {…}, "meta": {"gram": "negative", "whoPriority": "critical"}}], "…": []},
  "records": [
    {"year": 2023, "pathogen": "ABA", "antibiotic": "MEM", "phenotype": "CRAB", "level": "all", "ward": "all", "setting": "all",
     "specimen": "all", "isolates": 21432, "resistant_pct": 61.9, "precision": "text", "reportYear": 2023}
  ]
}
```
`slice` is present only on sliced endpoints. Use `dims` to label codes in any of the three languages. CSV files hold the
same records (UTF-8, header row). Localized fields are flattened to `country.zh-TW`, `country.en`, `country.ja`, and
arrays are joined with `|`.

## Examples

**JavaScript (browser / Node 18+)**
```js
const BASE = 'https://ancientsky.github.io/tw_amr_dashboard/api/v1';
const env = await (await fetch(`${BASE}/resistance/phenotype/CRKP.json`)).json();
const national = env.records
  .filter(r => r.level === 'all' && r.setting === 'all')
  .map(r => [r.year, r.resistant_pct, r.precision]);
console.log(env.provisional, national);
```

**curl + jq**
```bash
curl -s https://ancientsky.github.io/tw_amr_dashboard/api/v1/index.json | jq '.datasets[] | {id, records, provisional}'
curl -s https://ancientsky.github.io/tw_amr_dashboard/api/v1/glass/indicator/CR_ABA_BLOOD.json \
  | jq -r '.records[] | [.iso3, .year, .resistant_pct] | @tsv' | sort -k3 -n
curl -sO https://ancientsky.github.io/tw_amr_dashboard/api/v1/resistance.csv
```

**Python**
```python
import pandas as pd, requests
BASE = "https://ancientsky.github.io/tw_amr_dashboard/api/v1"
env = requests.get(f"{BASE}/resistance/pathogen/SAU.json", timeout=30).json()
df = pd.DataFrame(env["records"])
mrsa = df[(df.phenotype == "MRSA") & (df.setting == "all")].pivot(index="year", columns="level", values="resistant_pct")
antibiogram = pd.read_csv(f"{BASE}/resistance.csv").query("phenotype.isna() and year == 2024 and level == 'all'", engine="python")
```

**R**
```r
library(jsonlite)
base <- "https://ancientsky.github.io/tw_amr_dashboard/api/v1"
env  <- fromJSON(file.path(base, "resistance/phenotype/CRAB.json"))
subset(env$records, level == "all" & setting == "all")[, c("year", "resistant_pct", "precision")]
amr  <- read.csv(file.path(base, "resistance.csv"), encoding = "UTF-8")
```

## Embedding charts
To show a chart instead of raw data, use the embeddable widget (see `docs/EMBED.md`):
```html
<script src="https://ancientsky.github.io/tw_amr_dashboard/embed.js"
        data-chart="resistance-trend" data-pathogen="KPN" data-antibiotic="MEM" data-lang="zh-TW"></script>
```
The widget reads the same `public/data/*.json` files, and its provisional banners follow the same flags.

## Versioning, caching, citation
* `v1` paths are stable. Fields may be **added**, but existing fields are not renamed or removed within v1. Envelope
  `version` carries the data version, with a `-provisional` suffix on provisional datasets.
* Files change only when the content changes. `generatedAt` (in `index.json` and every envelope) and
  `meta.json → contentDigest` tell you when. GitHub Pages caches for about 10 minutes.
* Cite the original source listed in each envelope's `sources[]` (for resistance: Taiwan CDC, 臺灣抗生素抗藥性監視年報
  2022–2024), and mention TW-AMR Watch as the transcriber.
* Code lists, field meanings and the provisional policy are in [`docs/DATA.md`](DATA.md).
